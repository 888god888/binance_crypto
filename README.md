# Binance 短線選幣器 v6 — 返回空白修復

保留 v5 全部功能。本版修復手機從幣種頁返回時，偶發列表空白和搜尋結果消失問題。

- 返回先同步顯示排行榜，防止 WebView 的上一頁事件延遲留下空白。
- 瀏覽器 `popstate`、`pageshow` 重新同步詳細頁 / 排行榜狀態。
- 搜尋結果儲存在 sessionStorage，另存 localStorage 備援；不含帳密或 API 金鑰。
- 返回與重啟時還原表格水平位置、垂直位置、篩選參數與排序。
- 排行榜滾動停止後 350ms 保存，防止背景分頁被回收時遺失。

部署：將 ZIP 裡的 `index.html`、`css/`、`js/`、`config/` 全部覆蓋到 GitHub 專案根目錄。不要只上傳 index.html。

限制：瀏覽器若清除網站儲存資料、使用無痕模式或儲存額度已滿，無法保證跨重啟保存；回到上一次掃描結果並非即時更新的行情，需按掃描更新。
